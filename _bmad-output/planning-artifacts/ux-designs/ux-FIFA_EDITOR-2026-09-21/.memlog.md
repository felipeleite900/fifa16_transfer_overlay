- (decision) Forma: overlay ImGui em Rust (fifa_overlay), nao stack web/mobile tradicional. Estilizacao via tema custom do imgui-rs.
- (decision) Input: hibrido - mouse+teclado e gamepad, com foco visual claro em ambos os modos.
- (decision) Densidade de informacao: dupla visao alternavel pelo usuario - Tabular/densa (estilo planilha, varias colunas) e Cards espacosos (com foto/miniface do jogador via data/ui/imgAssets/heads).
- (decision) Tema de cor escolhido: Variacao 3 - Roxo + Verde-Campo. accent-primary roxo #b45cff, accent-secondary verde-campo #3ecf6e, tier-elite dourado #f5a623, tier-junior cinza-esverdeado #5c6b5f, bg-base quase preto com tint verde #0b0e0c, bg-panel rgba(16,20,18,0.93).
- (event) 4 temas de cor gerados em .working/color-themes-1.html para avaliacao visual do usuario.
- (decision) Modo de trabalho: Fast path.
- (decision) Idioma da UI: portugues.
- (decision) Navegacao principal: abas fixas no topo do painel - Olheiros | Missoes | Relatorios | Sonar.
- (decision) Sonar de Cobertura: mapa-mundi estilizado simplificado (silhuetas de continentes, sem fronteiras detalhadas de pais), desenhado via ImGui draw list customizado.
- (decision) Tipografia: fonte condensada tipo HUD esportivo para titulos/destaques, sans-serif legivel para corpo - fonte customizada via imgui-rs (nao a fonte padrao Proggy Clean).
- (decision) Acessibilidade: todo indicador critico (tier, status de missao, qualidade de relatorio) usa cor E label textual/icone junto - nunca cor isolada.
- (decision) Missao em andamento: barra de progresso visual + texto de estimativa (ex: pronto em ~12 dias de carreira), calculado a partir de GJUr.currdate decorrido / duracao estimada.
- (assumption) Fontes especificas nao escolhidas pelo usuario - assumido Oswald (condensada, para titulos/HUD) e Inter (legivel, para corpo) como placeholders concretos via imgui-rs, ajustavel na implementacao.
- (assumption) Reuso do componente Mapa Sonar em dois modos: Visualizacao (aba Sonar, mostra cobertura de missoes) e Selecao (dentro do formulario Nova Missao, para escolher paises/ligas/continentes do filtro geografico) - evita duplicar UI de mapa.
- (assumption) Escala de Qualidade do relatorio (baixa/media/alta) reutiliza visualmente a mesma paleta de 3 passos do Tier (cinza-junior/roxo-experiente/dourado-elite), sempre com label textual, para familiaridade visual - sao conceitos relacionados mas distintos.
- (event) Rascunho completo de DESIGN.md e EXPERIENCE.md escrito (Fast path). DESIGN.md com tokens completos (colors/typography/rounded/spacing/components) e 8 secoes de corpo. EXPERIENCE.md com IA de 8 superficies, 10 padroes de componente, 9 estados, 4 fluxos-chave nomeados (Felipe).
